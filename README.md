# Ogun State Business Grant Automation Project

## Overview
This project simulates an automated grant application workflow for Ogun State business owners using Google Sheets, Google Apps Script, and Power BI.

The system automates applicant screening, sends personalised email notifications to eligible applicants, and visualises applicant insights through an interactive dashboard.

---

## Features
- Applicant data management using Google Sheets
- Automated eligibility screening
- Email automation using Google Apps Script
- Power BI dashboard reporting
- Real-time applicant analysis
- Residency eligibility tracking

---

## Tools Used
- Google Sheets
- Google Apps Script
- Power BI
- Power Query
- Excel/CSV

---

## Automation Workflow
1. Applicants are stored in Google Sheets
2. The Apps Script checks residency eligibility
3. Eligible applicants receive automated emails
4. Email status is updated automatically
5. Power BI visualizes applicant insights

---

## Dashboard Insights
The dashboard includes:
- Total applicants
- Eligible applicants
- Approval rate
- Revenue analysis
- Gender distribution
- Residency distribution
- Business performance tracking

---

## Key Metrics
- 45 Total Applicants
- 29 Eligible Applicants
- 62% Approval Rate
- ₦414K Average Revenue
